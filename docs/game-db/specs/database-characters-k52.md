Status: offline, source-bound structural causality audit GO. The observed
type-82 causality expressions and native type-35 condition are supported as

## Boundary

K52 closes the 17 non-null causality rows left by K51 without treating the K3
sidecar as more complete than it is. K3 contains the 17 `leader_skills`
conditions, but none of the six referenced `skill_causalities` rows. The runner
therefore binds those six tuples separately to the exact first-party SQLite:

- size 95,428,608 bytes;
- SHA-256
  `3654eb7db9e18dfe4c238abd02bcc06a688ffa6f30aa1ad93fd108dcfeb78265`;
- regular, single-link, no-follow identity checked before, through and after a
  descriptor-bound read-only query;
- bridge input rehashed while it is streamed into SQLite `ro + immutable +
  query_only` mode.

The K3 `source` strings are neither used nor emitted. Only the structural
`compiled` member is accepted, and only as a positive integer or exact binary
`["&", left, right]` expression. The latter requires both leaf predicates.

The exact AArch64 ELF remains the K50/K51 runtime, SHA-256
`7d6c2c1e095fc20a71ec4764e88a17b4d4b82f3f12952b9ba8c6eb0405a7215a`.
K52 pins seven code regions, seven exact PLT/GOT call bindings, the complete
544-byte causality dispatch table and its ABS64 type-35 slot. The proven chain
is `execCausalityConditions -> checkCausalityConditions -> evaluate ->
executeCausalityFuncByJson/executeCausalityFuncBySkillCausalityId ->
SkillModel::getSkillCausalityById -> type-35 handler`. The handler reads only
`cau_val1`, inspects selected bits 0 through 31 and calls the pinned pure-element
bit-pattern helper.

The safe semantic statement is: every requested bit must be witnessed by at
least one eligible card in the runtime-inspected collection. K52 does not bind
human element/awakening names to masks, the complete contextual selection of
that collection, timing, recurrence, reset, duration or stacking behavior.

```text
  --sidecar-root <exact-k0-k7-root> \
  --production-root <exact-k7-production-root> \
  --fyi-root <exact-k7-fyi-root> \
  --k43-root <exact-k43-artifact-root> \
  --k46-root <exact-k46-artifact-root> \
  --k48-root <exact-k48-artifact-root> \
  --native-runtime <exact-libcocos2dcpp.so> \
  --database <exact-first-party-global-sqlite>
```

The runner requires `--expose-gc`, recomputes the K49/K50/K51 pins, validates
K48 source-bound before and after, and reloads K3, the SQLite rows and all native
evidence before returning GO. Its public report factory remains
`NOT_EXECUTED`. The CLI is stdout-only, timestamp-free and fail-closed below an
exclusive 1 GiB RSS ceiling. It has no writer, publisher, network, R2 or Android
path.
