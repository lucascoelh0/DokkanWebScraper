# Database Characters K45 - leader structural scope audit

Status: structural scope and next structural-ID-only projection GO. Leader
clause semantics, localized presentation, product replacement, consumers,
apply/overlay, authority, production, writer, publisher, network, R2, Android
and source removal remain NO-GO. Contract version `1.0.0`.

## Boundary

K45 asks which K3 leader-skill structures belong to the already-supported K43
state product. It does not interpret leader clauses, decide whether multiple
targets/effects compose as OR or sum, render text or select product authority.
Structured percent values are counted as opaque source values only.

The 59 unknown C3 rules are retained as a separate passive-mechanics comparison
boundary. C3 compares C2 passive rules to Team Analysis; it does not filter
leader scope. K45 does not change the K9 replacement decision.

## Sources and invocation

The runner has no defaults and requires Node garbage collection support:

```text
npm run audit:database-characters-leader-scope -- \
  --opt-in-k45 \
  --sidecar-root <exact-k0-k7-root> \
  --production-root <exact-k7-production-root> \
  --fyi-root <exact-k7-fyi-root> \
  --k43-root <exact-k43-artifact-root>
```

K43 is validated source-bound before and after the audit. K3 manifest, payload,
coverage and validation members must match the fixed refresh profile. Each
member is opened no-follow, required to be a regular single-link file of the
exact pinned size, read into only that bounded allocation, checked for EOF,
revalidated by handle/path identity and then hashed. The 81,356,220-byte raw K3
payload has SHA-256
`dcae7448442958f9142b185547c578219b614a4036027c342463eaee05f90fb5`.

The legacy K3 artifact necessarily parses its audit-only raw rows, but K45
immediately compacts and retains only state IDs, structural row references and
opaque numeric values. Raw rows and presentation are never emitted or used as
identity. K3 is loaded twice and its exact identities plus compact fingerprint
`d01a5aab35d7827fb37b3c1bf413bd17a980c31309f318f20002a618d32f092d`
must remain stable.

Direct report construction is non-authoritative and returns `NOT_EXECUTED`.
Only the runner's private finalization can report GO after all four source
checks complete.

## Real scope

| Measure | Count |
| --- | ---: |
| included supported states | 10,651 |

Maximum per-state counts are 18 effects, 54 targets and three percent values.
There are two states without effect references, 5,290 without target references
and 3,358 without structured-percent values. Absence is preserved; it is not
converted into a semantic zero or empty-clause interpretation.

The only exclusions are:

- `card-state:1010900:growth:716`
- `card-state:1010900:growth:717`
- `card-state:1010900:growth:718`

Two post-hardening runs produced byte-identical 5,429-byte reports with SHA-256
`23679af6c9b208ed66aebc032548545c5d4b922dd8c5e27973bcd1a33c218b34`.
Measured peak RSS was 1,010,200,576 bytes, below the exclusive 1 GiB limit.
Focused tests include oversized members, exact bounded reads, hard links and
identity replacement. The final domain suite passed 208 tests with nine
Windows-only symlink fixtures pending. Specialized contract review found no
remaining P0-P2 issue after the bounded K3 reader hardening.
