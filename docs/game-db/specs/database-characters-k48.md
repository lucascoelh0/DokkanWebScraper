# Database Characters K48 - leader association structural projection

Status: offline generation and source-bound validation GO. Semantic
association, leader-clause values/percentages, presentation, product
replacement/consumer, apply/overlay, authority, production, publisher,
network, R2 and Android remain NO-GO. Contract version `1.0.0`.

## Boundary

K48 materializes the K47-proven structural join for every supported K46 state.
Each state keeps its structural identities and leader-set ref. Each
source-ordered effect contains its `leader_skills` ref, structural
`targetSetId` and source-ordered `sub_target_types` refs. A null target-set ID
is valid only with an empty target array.

The redundant flattened targets, percentages, text, raw rows, source values
and `Character[]` are absent. The nested association proves provenance but does
not select OR/sum behavior, interpret efficacy types/values or claim a product
consumer contract.

## Invocation and artifact safety

```text
npm run run:database-characters-leader-association-projection -- \
  --opt-in-k48 \
  --sidecar-root <exact-k0-k7-root> \
  --production-root <exact-k7-production-root> \
  --fyi-root <exact-k7-fyi-root> \
  --k43-root <exact-k43-artifact-root> \
  --k46-root <exact-k46-artifact-root> \
  --output-root <existing-empty-local-root>
```

The runner requires a real K47 GO and source-bound K46, rebuilds the projection
twice, writes payload/coverage/validation create-only and the fixed manifest
last, then reconstructs and rereads the artifact. The final checks revalidate
K46, K3 and K47 after the artifact reread. Readers reject oversized files
before allocation and prove no-follow, single-link identity and EOF.

No automatic cleanup or unlink exists. A failed write can leave a partial
namespace; retry uses a new root unless separate cleanup is authorized.

The next useful gate is no longer a mechanical ID projection. It must decide
which first-party efficacy fields and percentage values form a leader clause,
how multiple clauses compose and what becomes product authority. That is a
material product/semantics decision and is not authorized by K48.
