# Database Team Analysis experiment v41 (DB42)

Status: experimental, non-production. Contract version: `0.41.0`.

DB42 resolves causality type `67` through the native causality dispatch. The handler reads `cau_val1` and `cau_val2`, ignores `cau_val3`, and dispatches current raw mode `0` to a structured card-category predicate and raw mode `2` to the native element/class bit-pattern predicate.

Both current submodes use `findSpecificGroup` party mode `0` with threshold `7`. The native loop visits seven player-party slots, does not accept unresolved `MasterCard` entries or callback-zero entries, short-circuits at seven accepted partners and returns true only when partner count is exactly seven. Category mode compares exact IDs returned by `Card::getCardCategories`. Class mask `32` accepts raw awakening values `{1,3}` and mask `64` accepts `{2,3}`; the Super/Extreme labels reuse DB35's independently validated raw class predicates.

The projected corpus contains 63 occurrences from 14 causality rows across 21 states and 46 passive skill IDs/rules: 31 category occurrences and 32 class occurrences. Every legacy condition was unknown. Raw mode `1` has a distinct native callee but no projected occurrence and is not semantically promoted by its symbol name. Other class/element masks, evaluation timing, duration, recurrence, reset/expiry and calculation bucket remain unknown.
